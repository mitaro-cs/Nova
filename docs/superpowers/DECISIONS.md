# Решения текущего этапа

- 12.11.2026: основная задача - подключаемые источники. Большой документ из вложения рассматривается как контекст; полный редизайн и обновление зависимостей в этот этап не включены. Позднее сообщение владельца с изображением задаёт референс профиля.
- Сохранён существующий поиск HTML-каталогов. Для полного импорта выбран явный JSON-контракт с версиями и стабильными ID, а не попытка считать любую страницу сайта каталогом. Это позволяет проверить атомарность, повторный импорт и сохранность каждого варианта.
- Источник связан с каждой ссылкой новой миграцией 31; старые миграции не изменены. Удаление источника скрывает варианты и запрещает новые обращения к потоку, сохраняя прогресс и записи.
- Ручной выбор администратора выше порядка подключённых источников. Отключённые источники не участвуют в выборе даже при сохранённом назначении.
- Обновление запускается хостом явно. Отсутствующие в новом JSON записи автоматически не удаляются. Для удаления устаревших вариантов остаются существующие действия со ссылками.
- Все внешние HLS-варианты сохраняются, даже если у них одинаковая высота. Safari выбирает индекс варианта, а не только разрешение. Субтитры hls.js отображаются штатным WebVTT-механизмом, поэтому локальные настройки оформления субтитров для них скрыты.
- [Референс профиля](../design/profile-reference-2026-11-12.png) сохранён без изменений; продуктовый профиль в этом этапе не редактировался.
- 12.11.2026: по прямому запросу владельца добавлены отдельные адаптеры девяти сайтов поверх JSON-импорта. Очередь страниц и результатов хранится в новых миграциях 32–33; неоднозначные совпадения IMDb не выбираются случайно. Полный набор источников не объявляется рабочим при HTTP 403, CAPTCHA или неизвестном формате плеера.
- DASH реализован отдельным лениво загружаемым dash.js 5.3.0, MPD переписывается quick-xml 0.42 с сохранением шаблонов сегментов. Исходные подписанные медиассылки Aksor не сохраняются вместо стабильного адреса плеера.
- Доступ через ручную проверку ограничен отдельным WebView источника и явным разрешением хоста на cookies точного HTTPS-origin в памяти. Личный профиль браузера не используется; автоматического обхода CAPTCHA нет. Неудачная проверка пользователя остаётся внешним ограничением, а не успешным импортом.
- По последующему запросу «дизайн и exe» владелец уточнил: дизайн относится к присланному профилю. Профиль перенесён в интерфейс с адаптацией для телефона и ПК; его прежние настройки, приватность и данные сохранены. Новому пользователю остаётся случайный персонаж из существующих 12, его выбор оформлен с подписями. Локальный Windows-установщик собирается с ffmpeg/ffprobe и проверенным штатным SDK ночного режима, без публикации и артефактов автообновления.

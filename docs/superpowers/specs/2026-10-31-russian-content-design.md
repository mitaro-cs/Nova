# Русский контент: имена людей, персонажи, должности

Дата: 2026-10-31. Часть 1 из 4 в плане «дизайн, работа сервиса, правила интерфейса, экраны».
Статус: черновик на проверку владельцем.

## Зачем

Владелец увидел на странице фильма из ленты блок «Актёры и съёмочная группа» с именами латиницей
(Damien Chazelle, Ryan Gosling) и ролями по-английски (Neil Armstrong, Ed White). Весь интерфейс Nova
русский, поэтому правило такое: **строка, которую видит зритель, не бывает латиницей, если для неё
есть способ получить русскую форму.** Сейчас имена, фото и роли берутся из GraphQL IMDb
(`server/src/meta/imdb.rs`, запросы `MAIN` и `EXTRA`), и перевода нет. Слово «Режиссёр» переводится
на фронте, остальное показывается как пришло.

## Что считаем успехом

- На страницах `/title/[id]` и `/ext/[id]` в блоке «Актёры и съёмочная группа» имена людей и
  персонажей по-русски («Дэмьен Шазелл», «Райан Гослинг», роль «Нил Армстронг»).
- Страница человека (`/director`) и поиск по имени работают как раньше, находят и по русскому, и по
  оригинальному написанию.
- «Нравится» человеку, любимые режиссёры и ссылки на людей не ломаются.
- Страница не ждёт перевода дольше 3 секунд.

## Не входит в эту часть

- Аудит остального (страны, языки, подписи кадров, названия сезонов, отзывы) - отдельный шаг на
  реальных данных, результат - список для следующей спецификации.
- Перевод описаний (уже есть `ruwiki::overview`).
- Правка перевода вручную из интерфейса (не нужна, пока нет жалоб).

## Решение

### Источники русского

| Что | Цепочка |
| --- | --- |
| Имя человека | Викиданные (`P345` = id IMDb, метка `ru`) -> транслитерация |
| Персонаж | TMDB `ru-RU` (если у хоста есть ключ) -> Википедия/Викиданные для известных людей -> транслитерация |
| Должность | фиксированный словарь: Режиссёр, Сценарист, Создатель, Актёр |
| Не латиница (китайские, корейские) | оставляем как есть, если русской формы нет |

TMDB для имён людей не берём: даже с `ru-RU` он часто отдаёт латиницу.

### Контракт данных

`meta::Person` получает поле `orig: Option<String>` - оригинальное написание. `name` становится
русским. Всё, что использует имя как ключ (`ext_people_names.name`, `like_person`, любимые
режиссёры, `personHref`), ищет по `id` (`nm…`), а без `id` - по `orig`, и по `name` как запасной
вариант. Старые записи в `titles.people` и `ext_titles.extra` без `orig` продолжают работать:
`orig` пустой, `name` - как был.

### Когда и как

1. Перевод выполняется один раз при загрузке описания (`meta::apply` для своих фильмов,
   `discover::detail` для ленты), до записи в базу.
2. Имена людей одной картины - один SPARQL-запрос `VALUES ?imdb { … }` (до 50 id), таймаут 3 с.
3. Не ответили Викиданные - показываем транслитерацию, запись помечаем `translit`, фоновая задача
   добирает перевод позже (раз в сутки, не чаще 3 попыток), страница не ждёт.
4. Результат по человеку кэшируется в новой таблице `person_names` (id, ru, orig, source, at,
   миграция следующая по номеру), чтобы один и тот же человек не запрашивался заново в другом фильме.
5. Транслитерация - `names::translit(&str) -> String`, чистая функция, правила ГОСТ-подобные
   для имён (Ch -> Ч, sh -> ш, ia -> ия, окончания -er/-ar и т.д.), покрыта таблицей тестов.

### Где менять

- Новый модуль `server/src/names.rs`: `translit`, `ru_names(app, ids)`, `ru_roles(app, imdb, roles)`.
- `meta/imdb.rs`: `parse_details` отдаёт `orig`; вызов перевода - в месте записи (`meta::apply`,
  `discover::detail`).
- `meta/tmdb.rs`: метод `credits_ru(imdb)` для персонажей (по ключу).
- `db.rs`: новая миграция `person_names`.
- Фронт: `web/src/routes/ext/[id]/+page.svelte` и `web/src/routes/title/[id]/+page.svelte` - показывают
  `p.name`, подсказка `title` - `p.orig`; `personHref` строит ссылку по `id`.
- Словарь должностей: расширить рядом с `meta::genre_ru`.

## Проверка

- Юнит-тесты: `translit` (таблица пар «оригинал -> ожидаемое»), разбор ответа Викиданных (макет
  JSON), словарь должностей.
- Сквозной тест `server/tests/`: страница фильма из ленты на демо-данных - в блоке актёров нет
  латиницы, кроме разрешённых исключений (аббревиатуры).
- e2e Playwright: `/ext/[id]` - текст `.cast` не содержит `[A-Za-z]{3,}`.
- Ручная проверка на «Первом человеке»: Шазелл, Гослинг, Клэр Фой, Джейсон Кларк.

## Изменения при составлении плана

- Перевод накладывается при отдаче страницы, а не при записи в базу: в `titles.people` и
  `ext_titles.extra` остаются оригинальные имена, ключи по имени не ломаются, уже сохранённые
  фильмы получают русские имена сразу. Фоновая задача не нужна: просроченную (24 ч) транслитерацию
  перепроверяет следующее чтение.
- Словарь должностей не нужен: «Режиссёр» и «Создатель» уже подставляет фронт.
- Персонажей через TMDB в этой части не переводим (имя актёра в TMDB не сопоставить с id IMDb без
  лишних запросов): персонажи транслитерируются.
- `person_names` хранит (id, ru, source, at), без `orig`: оригинал лежит в базе фильма.

## Дополнение: аудит латиницы (2026-11-01) и решения владельца

Аудит на живых страницах (скрипт обходил главную, фильмы, сериалы, обзор, страницы фильмов из
ленты, страницу человека, поиск, профиль). Имена людей уже по-русски; осталось:

| Где | Что видно | Решение владельца | Как делаем |
| --- | --- | --- | --- |
| Язык фильма | «English, Mandarin, Russian» | перевести | вызвать уже написанный `languagesRu` на `/title` и `/ext` |
| Слоган на `/ext` | «Why are they here?» | только русский | показывать, если в нём есть кириллица (`ruwiki::has_cyrillic`), иначе скрыть |
| «Другие названия» | испанские, немецкие, турецкие | оригинал и русские | оставлять оригинальное название и названия с кириллицей, остальные убрать |
| Названия без русского релиза (главная, обзор, поиск, фильмографии) | «Ghost Rider», «Street Fighter» | искать русское в Википедии | по id IMDb спросить Викиданные (метка `ru`), кэшировать, нет - оставить оригинал |
| `card.director` на карточках своих фильмов | «[США] Damien Chazelle» | перевести | русское имя из кэша `person_names` без сетевых запросов |
| `alt` фото на странице человека | «Christopher Nolan» | перевести | подставить русское имя |

Не входит и остаётся: отзывы пользователей IMDb, названия серий (`episode_locale`), описания
(`ruwiki::overview`) - отдельная проверка.

## Риски

- Транслитерация ошибается на редких именах (Chandler -> Чандлер вместо «Чэндлер»). Это приемлемо:
  лучше чем латиница, а Викиданные заменят при следующей попытке.
- Викиданные/TMDB недоступны (сервер владельца за ограничениями) - работает транслитерация, страница
  не зависит от сети.
- Ключ TMDB не обязателен: без него персонажи только транслитерируются.

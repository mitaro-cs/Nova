# Правила интерфейса и дизайна Nova (эталон - Rewind)

Дата: 2026-11-01. Часть 2 из 4 в плане «дизайн, работа сервиса, правила интерфейса, экраны».
Статус: реализовано в коде (1 ноября 2026), снимки до и после - `web/.shots/`; ждёт оценки владельца. Решение владельца: единый эталон для всех экранов -
макет Rewind (по нему уже сделана страница фильма: `web/src/lib/title/RewindHero.svelte`,
`web/src/lib/title/rewind-sheet.css`).

## Зачем

Сейчас страница фильма сделана по Rewind, а главная («Кинозал+», `ui/Showcase.svelte`), обзор,
профиль, чаты и плеер - по прежним решениям. Нужен один набор правил, чтобы любой экран выглядел
и вёл себя одинаково, а новый экран не приходилось подгонять «на глаз».

## Основа (уже в коде, фиксируем как правило)

**Цвет.** Фон страницы чёрный `--bg: #000`. Лист под кадром фильма - серая плита `#212121`.
Текст `--text #f5f5f7`, вторичный `--muted`, третичный `--faint`. Акцент белый; цветом фильма
(`card.accent`) красим только надпись героя и подсветку, не фон страницы. Линии - `--line`
(10% белого), сильные - `--line-strong`. Статусы: `--ok`, `--warn`, `--danger`, IMDb - `--imdb`.

**Шрифт.** Только Inter (лежит у нас, без внешних запросов), без курсива. Размеры в лист
и герой - в долях масштаба макета `--rw = min(100vw / 1440, 100svh / 900)`, с нижней границей
`max(Npx, calc(M * var(--rw)))`, чтобы на телефоне текст не мельчал.

**Сетка и отступы.** Боковое поле `--gutter: clamp(16px, 4vw, 56px)`, колонка листа 1200 в долях
`--rw`, до 1440 px шириной на больших экранах. Радиусы: `--radius 20px`, `--radius-sm 10px`.

**Раскладки по ширине.** ≥1000 px - капсула разделов в шапке (Главная, Фильмы, Сериалы, Обзор,
поиск); меню аватара - Люди, Чаты, Списки. Уже 1000 px - нижняя панель (Главная, Фильмы, Сериалы,
Обзор, «Я»), `--tabbar` задаёт отступ под неё. ≥981 px - лист Rewind; ниже - прежний
вид (телефон: `title/MobileHero`).

**Движение.** Только `transform` и `opacity`, ничего на больших контейнерах (не двигаем всю
страницу, нет анимации по прокрутке, нет анимированного размытия и теней). Появление страницы -
`page-in` (прозрачность, 0,32 с); смена кадра - две накладки и плавная прозрачность 0,9 с;
заставка при входе около 4,5 с. Слабая видеокарта на компьютере хоста - ограничение, а не
пожелание. Выключатель анимаций - `lib/motion.ts` (класс `no-motion`), системное
`prefers-reduced-motion` не учитываем (решение владельца).

**Стекло.** `backdrop-filter` только на маленьких капсулах (шапка, разделы, круглые кнопки),
не на больших площадях.

**Состояния.** Загрузка - заглушка с пульсом прозрачности (без бегущих градиентов), пустой
экран - `.empty` по центру, ошибка - русским текстом из `message` API. Ничего не должно
«дёргаться»: CLS < 0,02 (`e2e/smooth.spec.ts`), то, что вырастет после загрузки, не показывать
или резервировать место.

**Диалоги и клавиши.** Никаких `confirm()/alert()` (`ui/dialogs.svelte.ts`). Esc: `+layout`
сам закрывает верхний `<dialog>`; в плеере - меню, иначе назад к фильму.

**Тексты.** Всё по-русски (см. часть 1: правила языка и данных); обычный дефис « - », без
длинных тире; зрителям - «администрация/сервер Nova», не «хост».

**Выделение.** `body { user-select: none }`, выделяемое - `input`, `textarea`, `.selectable`.

## Решено владельцем (2026-11-01)

Макетов Rewind для остальных экранов нет: переносим язык страницы фильма (чёрный фон, серая плита
`#212121`, кружки, тонкие линии, масштаб `--rw`) на каждый экран по аналогии; главная остаётся
с героем во всю ширину.

# Единый вид экранов (язык Rewind) - план работ

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** все экраны Nova говорят на одном визуальном языке - том, что уже есть у страницы фильма (чёрный фон страницы, серая плита `#212121` с тонкими линиями-разделителями, кружки, капсулы, масштаб `--rw`), чтобы проект перестал выглядеть собранным из разных частей.

**Architecture:** общий слой `web/src/lib/ui/rewind.css` (глобальные токены и классы `.rw-sheet`, `.rw-block`, `.rw-h2`, `.rw-row`) и компонент `ui/Sheet.svelte` (заголовок на чёрном + плита с разделами); существующие `.btn`, `.chip`, `.card` из `app.css` подстраиваются под токены, а не заменяются; затем экраны переводятся по группам с проверкой снимками на четырёх ширинах. Главная и обзор остаются на чёрном с рядами (как у Apple TV/Rewind), но получают те же заголовки, чипы и карточки.

**Tech Stack:** SvelteKit 5, CSS (переменные, `calc` с `--rw`), Playwright.

**Spec:** `docs/superpowers/specs/2026-11-01-ui-rules-design.md` (эталон Rewind; решение владельца: остальные экраны - по аналогии со страницей фильма).

## Global Constraints

- Всё по-русски, обычный дефис « - », без длинных тире.
- Один шрифт Inter; движение только `opacity`/`transform`; `backdrop-filter` только на малых капсулах; в `app.css` не добавлять анимации на больших контейнерах.
- Размеры через масштаб макета: `max(Npx, calc(M * var(--rw)))`; боковое поле `--gutter`; колонка плиты 1200 в долях `--rw`, не шире 1440 px.
- Раскладки по ширине: ≥ 981 px - плита; ниже - плита на всю ширину без скруглений по бокам, разделы друг под другом; нижняя панель и `--tabbar` не трогать.
- Нельзя ломать: бюджет JS главной (80 КБ, `e2e/speed.spec.ts`), CLS < 0,02 (`e2e/smooth.spec.ts`), `e2e/layout.spec.ts` (ничего не шире экрана, текст и кнопки не пересекаются), `web/src/lib/paths.test.ts`.
- Стили страницы фильма (`rewind-sheet.css`, `RewindHero.svelte`) не менять по смыслу; их правила переезжают в общий слой без изменения вида (снимок до и после совпадает).
- Каждый шаг с видимым результатом проверяется снимками на 1440 × 900, 1024 × 768, 768 × 1024, 390 × 844 (скрипт Task 1) и сравнением «до/после»; снимки передаются владельцу.
- Проверки: `npm run check`, `npm test`, `npm run build`, `cargo build --release -p fsfy-server`, `npx playwright test --project=desktop --project=phone --project=tablet` с `FSFY_BIN=C:\Maison\Nova\target\release\fsfy.exe`.
- Коммиты - Conventional Commits, автор `Claude` через `-c user.name=Claude -c user.email=noreply@anthropic.com`, только локально; push, сборка и установка - по слову владельца.

## Review Focus

- Страница фильма после переноса стилей в общий слой выглядит так же (попиксельно близко на 1440 и 390).
- Админка с длинными таблицами и профиль с обложкой на телефоне не получают горизонтальной прокрутки.
- Тексты и кнопки внутри плиты читаются: контраст текста на `#212121` не ниже, чем сейчас на чёрном (≥ 4,5:1).
- Фокус с клавиатуры виден на плите (кольцо `--focus-shadow`-подобное, не серое на сером).
- Пустые состояния (`.empty`) по-прежнему по центру плиты.

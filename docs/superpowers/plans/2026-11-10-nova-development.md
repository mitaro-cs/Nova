# План развития Nova

1. Подготовить Rust, Node с npm, ffmpeg, зависимости и Playwright; уточнить наличие Windows SDK и рабочего Git-репозитория. Запустить исходные проверки и сохранить результаты.
2. Проверить референс, собрать HTML-макеты аккаунта, управления, плеера и профиля и снимки телефон/планшет/ПК/ТВ. Уточнить спецификацию по результатам аудита.
3. Исправить аккаунт и добавить проверки смены имени, логина, первого и существующего пароля, конкурирующих логинов и сессий.
4. Проверить безопасность и изоляцию чатов; реализовать экспорт и удаление с проверками прав и сохранности установки.
5. Инвентаризировать настройки и сделать общий интерфейс с серверными проверками.
6. Исследовать шесть сайтов из сети хоста, реализовать безопасные адаптеры и диагностику доступности, проверить дорожки и сценарии отказа.
7. Улучшить поиск и подсказки, затем плеер и профиль с сохранением существующих движков и правил платформ.
8. Доработать ТВ, измерить производительность и движение, проверить зависимости и README.
9. Для каждого этапа выполнить проверки и обновить CHANGELOG; коммитить только при наличии исходного Git-репозитория. После успешных проверок собрать Windows-установщик и передать пользователю.

Фактическое состояние: исходный каталог не содержит .git, cargo, npm и ffmpeg не найдены в PATH, web/node_modules отсутствует. Результаты сборки, производительности и работоспособности не установлены. Реальный телевизор в окружении не обнаружен.

Обновление: npm найден в C:/Program Files/nodejs и зависимости web установлены. Исходные проверки: 35 наборов Vitest, 170 тестов - успешно; svelte-check - 0 ошибок и предупреждений; сборка web и ТВ прошла при добавлении Node в PATH. Инструменты сборки сообщают об устаревшем alias и переопределённом paths, Vite предупреждает о большом чанке; принадлежность чанка главной пока не измерена. npm ci сообщает о 4 уязвимостях низкой серьёзности. Cargo, ffmpeg, серверные и Playwright-проверки, показатели производительности, макеты и установщик остаются непроверенными.

Продолжение: установлены Rust MSVC, Visual Studio Build Tools, ffmpeg и браузеры Playwright. Cargo fmt и cargo check сервера прошли; security - 7 тестов прошли. Полный запуск серверных тестов остановился на проверке времени ответа discover; повторный одиночный тест прошёл. Последовательный повтор набора запущен. Создан предварительный HTML-макет профиля, плеера и управления и снимки четырёх размеров; это ещё не полный комплект состояний и экранов.

# Подключаемые источники

## Ручное подключение и просмотр по запросу

В текущем интерфейсе «Управление → Каталог» хост самостоятельно добавляет адреса сайтов, выбирает тип, порядок и может отключить или удалить источник. Прежние карточки с пакетным импортом в интерфейсе убраны. При выборе фильма или конкретной серии Nova ищет доступный поток на включённых сайтах и передаёт его плееру; видеозаписи целиком не скачиваются и каталог сайта заранее не импортируется. Для работы отдельного сайта необходима поддержка его формата поиска и встроенного плеера; произвольный добавленный адрес сам по себе этого не гарантирует.

В каталоге хоста также есть форма «Источник для конкретного тайтла»: она ищет карточку IMDb с постером, предлагает найденные варианты подключённых сайтов и позволяет прикрепить ссылку вручную. Для сериала или аниме указываются сезон и серия. Прямой MP4/HLS может находиться на отдельном публичном CDN-домене; Nova проверяет адрес и формат, а фактическое воспроизведение зависит от ответа источника. В плеере доступны уровни качества и аудиодорожки, объявленные самим HLS/DASH-потоком; отсутствующие у потока варианты не создаются.

Проверка 12 ноября 2026: для YummyAnime найдена первая серия «Дороро», для mg.lordfilm.md — «Матрица». Lordserials находит страницу «Друзей», но её встроенный плеер Ladoni возвращает страницу 404, поэтому воспроизведение первой серии не подтверждено. Доступность остальных фильмов, всех серий, качеств и озвучек зависит от источников. Ранее сохранённые записи и прогресс не удаляются.

Следующий раздел описывает прежний интерфейс импорта и оставшиеся серверные возможности для совместимости; он не описывает текущий экран управления.

В «Управление → Каталог» хост добавляет домен, название и тип: всё, фильмы, сериалы или аниме. Здесь же находятся девять предложенных сайтов, YummyAnime, JSON-импорт, ручные ссылки и параметры внешних источников. Из «Обзора» доступна ссылка в этот раздел. Источники выключены, пока хост их не добавит. Порядок сверху вниз определяет приоритет импортированных вариантов, а «Выбрать для всех» у отдельного видео имеет преимущество над ним.

HTML-поиск на сайте и импорт полного каталога - разные возможности. Для HTML остаётся шаблон поиска с `{q}`. Для импорта нужен JSON Nova версии 1: его можно загрузить файлом или указать публичный адрес и нажать «Обновить из JSON». «Проверить» у источника с адресом JSON проверяет доступность и формат, но не заявляет успешное воспроизведение видео.

Пример: [catalog-source.example.json](catalog-source.example.json). Адреса example.com в нём условные - замените их реальными медиассылками своего каталога. `items` содержит уникальные `imdbId`, `title`, `kind` (`movie`, `series`, `anime`), необязательный `year` и непустой массив `streams`. Для фильма сезон и серия не указываются; для сериала нужны `season` (включая 0 для спецвыпусков) и `episode` от 1. Аниме может быть полнометражным или содержать серии.

У каждого потока свой стабильный `id` внутри тайтла, `url` на MP4/M4V/WebM/MOV/M3U8 и `label`. Необязательные `quality` и `voice` дополняют подпись в меню плеера. Каждую комбинацию качества и озвучки передайте отдельным элементом. Подписи не подтверждают техническое качество файла: импорт сохраняет сведения поставщика. Полный HLS-мастер сохраняет объявленные AUDIO/SUBTITLES-группы; интерфейс hls.js показывает все уровни качества, озвучки и субтитры. Для Safari добавлено переключение дорожек, которые браузер предоставляет через native audioTracks/textTracks; проверка на физическом устройстве ещё нужна.

Повторный импорт обновляет тот же `id`, сохраняя ID ссылки и прогресс. Отсутствующие варианты не удаляются. Ошибка любого элемента отклоняет весь импорт. Неизвестные поля отклоняются, чтобы не потерять непонятные данные молча. Предел одного импорта - 8 МБ, 10000 тайтлов и 50000 вариантов; большой каталог нужно передавать частями. Автоматического фонового обновления пока нет.

Выключенный или удалённый источник скрывается из выдачи ссылок и новых запросов потока Nova; уже загруженный в браузер буфер не отзывается. Связанные записи и прогресс остаются в базе. Если источник включить снова, они доступны без повторного импорта. Локальные папки подключаются существующим сканером через «Управление - Папки».

JSON и видео запрашиваются сервером через защиту публичных адресов и DNS. Для прямого HLS вложенные адреса должны оставаться на том же домене потока; произвольные CDN не разрешаются автоматически. Импорт не выполняет JavaScript сайтов, не обходит DRM, авторизацию, CAPTCHA или антибот.

Для девяти запрошенных сайтов есть отдельные карточки «Источники из вашего списка». «Подключить» включает источник, «Импортировать сайт» запускает фоновую задачу. Для сайтов используются отдельные адаптеры, JSON Nova им не нужен. Страницы и записи очереди сохраняются в SQLite (миграции 32–33); после остановки приложения импорт можно продолжить кнопкой. Автоматического возобновления при запуске нет. Обход Lordserials включает найденные разделы и их пагинацию, а не только главную подборку. Обход больших каталогов идёт постепенно; полный каталог всех сайтов в ходе разработки не скачивался.

Все найденные варианты YummyAnime сохраняются, включая спецвыпуски и неподдержанные плееры с предупреждением. Aksor раскрывается в каждое непустое качество из API и разрешается заново при просмотре. CVH сопоставляется по точным озвучке, серии и сезону (если указан); сохраняются HLS и все непустые MPEG-варианты API. Подписанные адреса CVH разрешаются заново по стабильному идентификатору видео. Для Namy/Nextembed сохраняется адрес плеера и точная серия; HLS дополняется названиями аудиодорожек и отдельными WebVTT-субтитрами. DASH Aksor проходит через прокси MPD/сегментов Nova, dash.js загружается только в плеере DASH. Шаблоны номеров сегментов сохраняются.

Неточное или неоднозначное совпадение IMDb не привязывается автоматически: карточка получает отдельный ID источника, а в диагностике можно назначить IMDb вручную. Счётчик «Импортировано» включает такие карточки; «Требуют внимания» включает ошибки, неподтверждённые потоки и отсутствие привязки. Импорт записи не равен подтверждённому воспроизведению.

В настольном приложении хост может открыть отдельное окно сайта и вручную пройти проверку. «Использовать сессию» разрешает серверу использовать cookies этого окна только для точного HTTPS-origin источника и только до закрытия Nova. Они не передаются зрителям, не возвращаются в API и не копируются из личного браузера. «Забыть сессию» отзывает разрешение. Сайт может привязывать проверку к браузеру или сети, поэтому перенос cookies не гарантирует доступ. Автоматического решения CAPTCHA нет; при отказе задача сохраняет причину и остаётся доступной для повторного запуска.

Проверка сетевых сегментов подтверждает доступность данных, но не декодирование видео реальным браузером или телевизором. Поддержка всех девяти сайтов, всех озвучек, Safari/ТВ и 4K пока не завершена.

# Техническое задание: Nova

Редакция 1 · 21 ноября 2026 · текущая версия 2.1.1-beta

## 1. Назначение

Nova - домашний кинотеатр. Приложение хоста (Windows, Mac, Linux) раздаёт фильмы и сериалы со своего диска, зрители смотрят в браузере, на телефоне и телевизоре. Описания, постеры и кадры берутся только с IMDb; сторонние сайты используются лишь как источники видео для просмотра и в базу фильмов не попадают.

## 2. Роли

| Роль | Кто | Права |
| --- | --- | --- |
| Хост | владелец компьютера | всё: папки, люди, доступ, выпуск, администраторы |
| Администратор | назначает хост | управление библиотекой и людьми |
| Зритель | зарегистрированный человек | просмотр, отметки, отзывы, друзья, чаты, комнаты |

Управление из интернета - только при включённой настройке и втором шаге входа.

## 3. Платформы и среда

- Сервер: Rust (axum, tokio, SQLite в WAL), один процесс в приложении Tauri 2.
- Интерфейс: SvelteKit 3 + Svelte 5, одна страница; ТВ - отдельная лёгкая сборка (Chrome 69, Tizen 5.5).
- Порты: общий 17480 (`0.0.0.0`) и окна хоста 17481 (`127.0.0.1`).
- Доступ из интернета: CloudPub (рекомендуется), fxtunnel, свой адрес, только дом.
- Всё на русском: интерфейс, ошибки, документы. Исключения - названия «Nova» и «IMDb».

## 4. Функциональные требования

### 4.1 Библиотека
- Папки хоста, слежение за изменениями, перетаскивание файлов в окно.
- Распознавание названия, года, сезона и серии по имени файла и папки.
- Описание, постер и кадр - с IMDb; русское описание - IMDb или начало статьи русской Википедии.
- Фильм без описания IMDb не показывается в ленте и подборках.

### 4.2 Плеер
- Цепочка режимов: прямой файл, перепаковка, копия «Оригинал» (только Safari), адаптивный HLS; переход по цепочке с того же места.
- Озвучки, субтитры (WebVTT), качество, скорость, громкость до 200 %, картинка в картинке.
- Минималистичный вид: название и «Закончится в», тонкая линия, одна строка значков. Пауза: кадр темнеет, крупно название и «Продолжить». На паузе управление не прячется; при перемотке крупное название уходит.
- Пропуск заставки, следующая серия, запоминание места на всех устройствах.

### 4.3 Главная, «Что смотреть», «Обзор»
- Главная: карусель героя, «Продолжить просмотр» со стрелками прокрутки, ряды.
- «Что смотреть» (афиша): фильм дня на кадре, «Спросите Nova» (жанры, длина, годы, десятилетия, название; дополнительно поиск по всему IMDb), подборки по идее (открываются под своей карточкой), «Вы не досмотрели», «Популярное на IMDb», лента карточек только с кадром.
- «Обзор»: «Открытия» (подборка дня, главные списки, календарь премьер), жанры, ряды IMDb, поиск по IMDb.
- Аниме - только в разделе «Аниме».

### 4.4 Фильм и сериал
- Плашка действий: «Смотрел / Любимый / Хочу» в кругах, оценка звёздами, «Смотреть вместе», «В подборки», «Отзыв».
- Сериал: сезоны, серии одной ширины, отметка «посмотрел» у серии.
- Страница человека: лучшие работы (только фильмы и сериалы), без отдельных серий и игр.

### 4.5 Профиль
- Компьютер - «Пульт»: слева закреплённая колонка (стена постеров, портрет в кольце уровня, звание, медали, плитки разделов, друзья, «Поделиться»), справа вкладки «Обзор / Статистика / Просмотрено / Отзывы».
- Владелец сам решает, кто видит статистику, просмотренное и отзывы (все, друзья, только я).

### 4.6 Люди, чаты, подборки, комнаты
- Дружба, сообщения друзьям (с фильмом карточкой), общие подборки.
- Комнаты совместного просмотра закрыты для чужих: входят создатель и позванные. Хост может позвать любого зрителя, остальные - только друзей.
- Очередь комнаты: порядок, принятие и «включить» - только у создателя; гости предлагают; ссылки проверяет сервер (Rutube, VK, YouTube, прямой файл, сайты хоста).
- Голос в комнате - WebRTC между браузерами.

### 4.7 Управление
- Мастер настройки (пять шагов, живые проверки, замер скорости).
- «Обзор»: оценка здоровья из 100, режимы сервера («Только дом», «Семья и друзья», «Открытый»), недельные тренды, графики, диск, кто смотрит, ошибки.
- Люди, приглашения, журнал входов, копии базы, обновление приложения.

### 4.8 Приватность и согласие
- Страницы `/legal/privacy` и `/legal/terms` с оглавлением и номером редакции.
- Регистрация - только с согласием (проверяет и интерфейс, и сервер); прежние аккаунты принимают документы при входе, до принятия сервис закрыт.
- Пароли - Argon2id, сессии - хеш ключа, журнал входов без адресов, EXIF у фото удаляется.

## 5. Нефункциональные требования

| Требование | Значение |
| --- | --- |
| Первый экран главной | до 1 с в домашней сети |
| Ответ API библиотеки и ленты | до 50 мс |
| JS главной | не больше 88 КБ сжатого |
| Сдвиги вёрстки (CLS) | меньше 0,02 |
| Анимации | только transform и opacity |
| Стекло (backdrop-filter) | только на маленьких плашках |
| Цвета | акцент только белый; цвет - лишь для состояния |
| Тексты | обычный дефис « - », без длинных тире |
| Внешние запросы из интерфейса | нет: картинки сервер скачивает к себе |
| Ожидание внешних сервисов на странице | не дольше 1,5 с, дальше - в фоне |

## 6. Выпуск и проверки

- Версия - в `Cargo.toml`, `tauri.conf.json`, `web/package.json`, `desktop/package.json` и `CHANGELOG.md`.
- Пуш в ветку `miaro` собирает выпуск (Windows, Mac, Linux) с подписанным `latest.json`; перед установкой база копируется в `backups/`.
- Перед выпуском: `cargo fmt`, `clippy -D warnings`, `cargo test`, `npm run check`, `npm test`, `npm run build`, e2e (вёрстка, целостность, скорость, плавность). Видео-тесты - отдельная необязательная задача CI.

## 8. Критерии приёмки

- Все проверки раздела 6 зелёные.
- На каждом экране нет ошибок, битых картинок и переполнения по ширине на телефоне, планшете и компьютере.
- Нет фильмов без описания IMDb в ленте и подборках; нет нерусских описаний в интерфейсе.
- Комната не открывается по коду для незваного человека.
- Регистрация невозможна без согласия; прежний аккаунт видит окно согласия.

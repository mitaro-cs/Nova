HTTP 401 и 403

Изолированный стенд на 127.0.0.1. Кнопки показывают учебные сценарии только на этом локальном сервере.

Ответ сервера

Выберите демонстрацию.

Учебный вывод: заголовки клиента и повторы не дают разрешения. 401 требует предусмотренной аутентификации; 403 означает отказ по политике. Для реального ресурса нужен официальный доступ от владельца.

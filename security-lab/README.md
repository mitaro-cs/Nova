# Nova 403 Lab

Учебный стенд HTTP 401/403 для занятий по сетевой безопасности. Это отдельное приложение без зависимостей и без сетевых обращений к внешним сайтам.

## Запуск EXE

Запустите `artifacts/Nova-403-Lab.exe`, затем откройте `http://127.0.0.1:8765` в браузере. Окно консоли показывает адрес и закрывается по Ctrl+C.

В примерах LordFilm, Lordserials и YummyAnime показаны только фиктивные ответы 403. Приложение не запрашивает эти домены, не собирает ссылки на видео и не выполняет обхода реальной защиты.

## Пересборка под Windows

```powershell
cargo build --release --manifest-path security-lab/Cargo.toml
Copy-Item security-lab/target/release/Nova-403-Lab.exe artifacts/Nova-403-Lab.exe
```

Исполняемый файл привязывает HTTP-сервер исключительно к `127.0.0.1:8765`.
